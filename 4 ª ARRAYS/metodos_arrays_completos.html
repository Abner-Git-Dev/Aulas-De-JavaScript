📚 Métodos de Arrays em JavaScript - Guia Completo

Guia completo com todos os métodos de arrays explicados detalhadamente.

1. Criação de Arrays

O que faz: Cria uma lista ordenada de valores.
Quando usar: Quando você precisa armazenar múltiplos valores em uma única variável.
Importante: Arrays são indexados a partir de 0 (primeiro elemento é índice 0).
// Array de strings
const alunos = ['Luiz', 'Samira', 'João'];

// Array de números
const numeros = [1, 2, 3, 4, 5];

// Array vazio
const vazio = [];

// Array misto
const misto = ['texto', 10, true, null];
Resultado: Arrays criados com diferentes tipos de dados

2. Acesso por Índice

O que faz: Acessa elementos específicos do array usando seu índice.
Quando usar: Quando você precisa obter ou modificar um elemento específico.
Importante: Índices começam em 0. Último índice = length - 1.
const alunos = ['Luiz', 'Samira', 'João'];
// 0 1 2

console.log(alunos[0]); // 'Luiz'
console.log(alunos[1]); // 'Samira'
console.log(alunos[2]); // 'João'
Resultado: 'Luiz', 'Samira', 'João'

3. push()

O que faz: Adiciona um ou mais elementos ao final do array.
Quando usar: Quando você precisa adicionar novos elementos ao final da lista.
Importante: Modifica o array original e retorna o novo tamanho.
const alunos = ['Luiz', 'Samira', 'João'];

alunos.push('Abner');
console.log(alunos); // ['Luiz', 'Samira', 'João', 'Abner']

alunos.push('Felipe', 'Diego'); // Adiciona múltiplos
console.log(alunos); // ['Luiz', 'Samira', 'João', 'Abner', 'Felipe', 'Diego']
Resultado: Elementos adicionados ao final do array

4. unshift()

O que faz: Adiciona um ou mais elementos no início do array.
Quando usar: Quando você precisa adicionar novos elementos no começo da lista.
Importante: Modifica o array original e retorna o novo tamanho.
const alunos = ['Luiz', 'Samira', 'João'];

alunos.unshift('Rafael');
console.log(alunos); // ['Rafael', 'Luiz', 'Samira', 'João']

alunos.unshift('Kaio', 'Pedro'); // Adiciona múltiplos
console.log(alunos); // ['Kaio', 'Pedro', 'Rafael', 'Luiz', 'Samira', 'João']
Resultado: Elementos adicionados no início do array

5. pop()

O que faz: Remove o último elemento do array.
Quando usar: Quando você precisa remover o último elemento da lista.
Importante: Modifica o array original e retorna o elemento removido.
const alunos = ['Luiz', 'Samira', 'João'];

const removido = alunos.pop();
console.log(removido); // 'João'
console.log(alunos); // ['Luiz', 'Samira']
Resultado: 'João' removido, array agora é ['Luiz', 'Samira']

6. shift()

O que faz: Remove o primeiro elemento do array.
Quando usar: Quando você precisa remover o primeiro elemento da lista.
Importante: Modifica o array original e retorna o elemento removido.
const alunos = ['Luiz', 'Samira', 'João'];

const removido = alunos.shift();
console.log(removido); // 'Luiz'
console.log(alunos); // ['Samira', 'João']
Resultado: 'Luiz' removido, array agora é ['Samira', 'João']

7. length

O que faz: Retorna o número de elementos no array.
Quando usar: Quando você precisa saber quantos elementos existem no array.
Importante: É uma propriedade, não um método (não usa parênteses).
const alunos = ['Luiz', 'Samira', 'João'];

console.log(alunos.length); // 3

alunos.push('Abner');
console.log(alunos.length); // 4
Resultado: 3, depois 4
Adicionar usando length: alunos[alunos.length] = 'novo' adiciona ao final

8. splice()

O que faz: Remove ou adiciona elementos em qualquer posição do array.
Quando usar: Quando você precisa modificar o array em uma posição específica.
Importante: Modifica o array original. Primeiro parâmetro = índice, segundo = quantidade a remover.
const alunos = ['Luiz', 'Samira', 'João', 'Abner'];

// Remover 1 elemento a partir do índice 1
alunos.splice(1, 1);
console.log(alunos); // ['Luiz', 'João', 'Abner']

// Adicionar 'Felipe' no índice 1
alunos.splice(1, 0, 'Felipe');
console.log(alunos); // ['Luiz', 'Felipe', 'João', 'Abner']
Resultado: Elementos removidos/adicionados em posição específica

9. slice()

O que faz: Retorna uma cópia de parte do array sem modificar o original.
Quando usar: Quando você precisa obter uma parte do array sem alterá-lo.
Importante: Não modifica o array original. Primeiro parâmetro = início, segundo = fim (exclusivo).
const alunos = ['Luiz', 'Samira', 'João', 'Abner', 'Felipe'];

const parte = alunos.slice(1, 3);
console.log(parte); // ['Samira', 'João']
console.log(alunos); // ['Luiz', 'Samira', 'João', 'Abner', 'Felipe'] (original intacto)
Resultado: ['Samira', 'João'] (cópia, original não modificado)

10. indexOf()

O que faz: Retorna o índice da primeira ocorrência de um elemento.
Quando usar: Quando você precisa encontrar a posição de um elemento no array.
Importante: Retorna -1 se o elemento não for encontrado.
const alunos = ['Luiz', 'Samira', 'João', 'Samira'];

console.log(alunos.indexOf('Samira')); // 1 (primeira ocorrência)
console.log(alunos.indexOf('João')); // 2
console.log(alunos.indexOf('Diego')); // -1 (não encontrado)
Resultado: 1, 2, -1

11. lastIndexOf()

O que faz: Retorna o índice da última ocorrência de um elemento.
Quando usar: Quando você precisa encontrar a última posição de um elemento.
Importante: Retorna -1 se o elemento não for encontrado.
const alunos = ['Luiz', 'Samira', 'João', 'Samira'];

console.log(alunos.lastIndexOf('Samira')); // 3 (última ocorrência)
console.log(alunos.lastIndexOf('João')); // 2
console.log(alunos.lastIndexOf('Diego')); // -1 (não encontrado)
Resultado: 3, 2, -1

12. includes()

O que faz: Verifica se um elemento existe no array. Retorna true ou false.
Quando usar: Quando você precisa saber se um elemento está presente no array.
Importante: Mais moderno e legível que indexOf().
const alunos = ['Luiz', 'Samira', 'João'];

console.log(alunos.includes('Samira')); // true
console.log(alunos.includes('Diego')); // false
Resultado: true, false

13. join()

O que faz: Junta todos os elementos do array em uma string.
Quando usar: Quando você precisa converter um array em string.
Importante: Por padrão usa vírgula como separador, mas pode personalizar.
const alunos = ['Luiz', 'Samira', 'João'];

console.log(alunos.join()); // 'Luiz,Samira,João'
console.log(alunos.join(' - ')); // 'Luiz - Samira - João'
console.log(alunos.join(' / ')); // 'Luiz / Samira / João'
Resultado: 'Luiz,Samira,João', 'Luiz - Samira - João', 'Luiz / Samira / João'

14. reverse()

O que faz: Inverte a ordem dos elementos do array.
Quando usar: Quando você precisa inverter a ordem dos elementos.
Importante: Modifica o array original.
const alunos = ['Luiz', 'Samira', 'João'];

alunos.reverse();
console.log(alunos); // ['João', 'Samira', 'Luiz']
Resultado: ['João', 'Samira', 'Luiz'] (ordem invertida)

15. sort()

O que faz: Ordena os elementos do array.
Quando usar: Quando você precisa organizar os elementos em ordem.
Importante: Modifica o array original. Por padrão converte para string e ordena.
const numeros = [3, 1, 4, 1, 5, 9, 2, 6];

numeros.sort();
console.log(numeros); // [1, 1, 2, 3, 4, 5, 6, 9]

const nomes = ['Luiz', 'Samira', 'João'];
nomes.sort();
console.log(nomes); // ['João', 'Luiz', 'Samira'] (ordem alfabética)
Resultado: Array ordenado
Para números: sort((a, b) => a - b) ordena numericamente

16. instanceof Array

O que faz: Verifica se uma variável é um array. Retorna true ou false.
Quando usar: Quando você precisa validar se uma variável é do tipo array.
Importante: Útil para verificar tipos de dados.
const alunos = ['Luiz', 'Samira', 'João'];
const texto = 'Não é array';
const numero = 10;

console.log(alunos instanceof Array); // true
console.log(texto instanceof Array); // false
console.log(numero instanceof Array); // false
Resultado: true, false, false

17. concat()

O que faz: Junta dois ou mais arrays em um novo array.
Quando usar: Quando você precisa combinar múltiplos arrays.
Importante: Não modifica os arrays originais, retorna um novo array.
const alunos1 = ['Luiz', 'Samira'];
const alunos2 = ['João', 'Abner'];

const todos = alunos1.concat(alunos2);
console.log(todos); // ['Luiz', 'Samira', 'João', 'Abner']
console.log(alunos1); // ['Luiz', 'Samira'] (original intacto)
Resultado: ['Luiz', 'Samira', 'João', 'Abner'] (novo array)
