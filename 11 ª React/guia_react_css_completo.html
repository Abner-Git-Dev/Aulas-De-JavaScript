📚 Guia Completo React + CSS

🎯 Conceitos de React Usados

Conceitos Fundamentais

1. Componentes Funcionais

O que é: Funções JavaScript que retornam JSX.
Para que serve: Criar blocos reutilizáveis de interface.
Importância: Base do React, permite organizar código em partes pequenas.
function Home() { return ( <div>Olá Mundo</div> ); } export default Home;
Quando usar: Sempre que precisar criar um elemento de UI.
Componentes sempre começam com letra maiúscula.

2. JSX

O que é: Sintaxe que mistura HTML com JavaScript.
Para que serve: Escrever interface de forma declarativa.
Importância: Torna o código mais legível e intuitivo.
return ( <div className='container'> <h1>Título</h1> <p>Texto</p> </div> );
Quando usar: Sempre que escrever a UI de um componente.
Use className em vez de class no JSX.

3. Importar Componentes

O que é: Importar componentes de outros arquivos.
Para que serve: Usar componentes criados em outros arquivos.
Importância: Organização do código e reutilização.
import Home from './Home'; import Home from './pages/Home';
Quando usar: Quando precisar usar um componente em outro arquivo.
Caminho relativo deve estar correto.

4. Renderizar Componente

O que é: Colocar o componente na página.
Para que serve: Exibir o componente no navegador.
Importância: Ponto de entrada da aplicação.
import ReactDOM from 'react-dom/client'; import Home from './Home'; ReactDOM.createRoot(document.getElementById('root')).render( <Home /> );
Quando usar: No arquivo principal (main.jsx).
Deve haver um elemento com id="root" no HTML.
Manipulação de Dados

5. map

O que é: Método de array que itera e retorna elementos.
Para que serve: Renderizar listas de componentes.
Importância: Essencial para mostrar dados dinâmicos.
const users = [ { id: 1, name: 'Abner' }, { id: 2, name: 'Samira' } ]; {users.map(user => ( <div key={user.id}> <p>{user.name}</p> </div> ))}
Quando usar: Sempre que precisar renderizar uma lista.
Sempre usar key único para cada elemento.

6. Arrays de Objetos

O que é: Lista de objetos com dados.
Para que serve: Armazenar dados estruturados.
Importância: Forma comum de receber dados de APIs.
const users = [ { id: '2342asdasds', name: 'Rodolfo', age: 33, email: 'rod@email.com' }, { id: '2342asdasdadsas', name: 'Abner', age: 23, email: 'abn@email.com' } ];
Quando usar: Para armazenar dados de usuários, produtos, etc.
Cada objeto deve ter um identificador único (id).
Estilização e Recursos

7. Importar CSS

O que é: Importar arquivo de estilos CSS.
Para que serve: Aplicar estilos ao componente.
Importância: Separação de estilo e lógica.
import './style.css';
Quando usar: No topo do componente que precisa de estilos.
CSS importado afeta apenas o componente e seus filhos.

8. Importar Imagens

O que é: Importar arquivos de imagem.
Para que serve: Usar imagens nos componentes.
Importância: Vite otimiza imagens automaticamente.
import Trash from '../../assets/trash.svg'; <img src={Trash} alt="trash" />
Quando usar: Quando precisar exibir imagens.
Caminho relativo deve estar correto.

9. className

O que é: Atributo para adicionar classes CSS no JSX.
Para que serve: Aplicar estilos CSS aos elementos.
Importância: Diferente de class do HTML normal.
<div className='container'> <button className='cadastrar-button'>
Quando usar: Sempre que precisar aplicar estilos CSS.
Em JSX, use className, não class.

10. key

O que é: Atributo único para identificar elementos em listas.
Para que serve: Ajudar React a identificar quais itens mudaram.
Importância: Melhora performance e evita bugs.
{users.map(user => ( <div key={user.id}> {user.name} </div> ))}
Quando usar: Sempre ao usar map para renderizar listas.
Key deve ser único e estável (não usar index).

11. Fragment

O que é: Agrupa elementos sem criar div extra.
Para que serve: Retornar múltiplos elementos sem wrapper.
Importância: Evita divs desnecessárias no DOM.
return ( <> <h1>Título</h1> <p>Texto</p> </> );
Quando usar: Quando precisa retornar múltiplos elementos.

🎨 Conceitos de CSS Usados

Reset e Base

1. Reset CSS

O que é: Remove estilos padrão do navegador.
Para que serve: Começar com estilos consistentes.
Importância: Evita diferenças entre navegadores.
* { margin: 0; padding: 0; box-sizing: border-box; font-family: "Poppins", sans-serif; }
Quando usar: No início do CSS global.
box-sizing: border-box facilita cálculos de tamanho.

2. Body Global

O que é: Estilos aplicados ao body da página.
Para que serve: Definir tamanho e fundo da página.
Importância: Base visual da aplicação.
body { min-height: 100vh; width: 100vw; background: linear-gradient(180deg, #363467 0%, rgba(30, 29, 79, 0.8) 100%); }
Quando usar: Para definir aparência geral da página.
100vh = altura total da viewport, 100vw = largura total.
Layout com Flexbox

3. Flexbox

O que é: Sistema de layout unidimensional.
Para que serve: Alinhar e distribuir elementos.
Importância: Layout moderno e responsivo.
.container { display: flex; align-items: center; flex-direction: column; }
Quando usar: Para alinhar elementos em linha ou coluna.
display: flex ativa o modo flexbox.

4. flex-direction

O que é: Define direção dos itens flex.
Para que serve: Organizar elementos em linha ou coluna.
Importância: Controla layout principal.
form { flex-direction: column; }
Quando usar: Para definir se elementos ficam em linha ou coluna.
column = vertical, row = horizontal (padrão).

5. align-items

O que é: Alinha itens no eixo transversal.
Para que serve: Centralizar elementos verticalmente.
Importância: Alinhamento preciso.
.container { align-items: center; }
Quando usar: Para centralizar verticalmente.
center = centraliza, flex-start = topo, flex-end = base.

6. justify-content

O que é: Alinha itens no eixo principal.
Para que serve: Distribuir espaço horizontalmente.
Importância: Espaçamento entre elementos.
.card { justify-content: space-between; }
Quando usar: Para distribuir elementos horizontalmente.
space-between = espaços iguais entre itens.

7. gap

O que é: Espaçamento entre itens flex.
Para que serve: Criar espaços consistentes.
Importância: Mais simples que margin.
form { gap: 30px; }
Quando usar: Para criar espaçamento entre elementos.
Funciona apenas com display: flex ou grid.
Estilização Visual

8. border-radius

O que é: Arredonda cantos dos elementos.
Para que serve: Criar bordas arredondadas.
Importância: Design moderno e suave.
form { border-radius: 10px; } .cadastrar-button { border-radius: 30px; } input { border-radius: 30px; }
Quando usar: Para criar cantos arredondados.
Valores maiores = mais arredondado, 50% = círculo.

9. background-color

O que é: Cor de fundo do elemento.
Para que serve: Definir cor de fundo.
Importância: Identificação visual.
form { background-color: #2e2d4e; } .card { background-color: #2e2d4e; }
Quando usar: Para definir cor de fundo.
Pode usar hex, rgb, rgba, ou nome da cor.

10. linear-gradient

O que é: Gradiente linear de cores.
Para que serve: Criar fundos com transição de cores.
Importância: Design visual atraente.
body { background: linear-gradient(180deg, #363467 0%, rgba(30, 29, 79, 0.8) 100%); }
Quando usar: Para criar fundos com gradiente.
180deg = de cima para baixo.

11. color

O que é: Cor do texto.
Para que serve: Definir cor do texto.
Importância: Legibilidade e design.
h1 { color: aliceblue; } p { color: #fff; } input { color: #ffff; }
Quando usar: Para definir cor do texto.
Use cores com bom contraste com o fundo.

12. font-size

O que é: Tamanho da fonte.
Para que serve: Definir tamanho do texto.
Importância: Hierarquia visual.
h1 { font-size: 28px; } .cadastrar-button { font-size: 14px; } input { font-size: 16px; }
Quando usar: Para definir tamanho do texto.
Use unidades relativas (rem, em) para responsividade.

13. font-weight

O que é: Espessura da fonte.
Para que serve: Definir negrito ou normal.
Importância: Hierarquia visual.
.cadastrar-button { font-weight: bold; } p { font-weight: bold; } p span { font-weight: normal; }
Quando usar: Para destacar texto importante.
bold = 700, normal = 400.
Espaçamento

14. padding

O que é: Espaçamento interno do elemento.
Para que serve: Criar espaço dentro do elemento.
Importância: Espaçamento interno do conteúdo.
form { padding: 30px; } .card { padding: 10px; } input { padding-left: 10px; }
Quando usar: Para criar espaço dentro do elemento.
padding-left = apenas esquerda, padding = todos os lados.

15. margin

O que é: Espaçamento externo do elemento.
Para que serve: Criar espaço entre elementos.
Importância: Espaçamento externo.
form { margin-bottom: 20px; } .card { margin: 10px; }
Quando usar: Para criar espaço entre elementos.
margin-bottom = apenas abaixo, margin = todos os lados.
Bordas

16. border

O que é: Borda do elemento.
Para que serve: Criar borda ao redor do elemento.
Importância: Delimitação visual.
input { border: 1px solid #48456c; } .cadastrar-button { border: none; }
Quando usar: Para criar borda ou remover.
border: none remove a borda.

17. outline

O que é: Borda de foco do elemento.
Para que serve: Indicar elemento focado.
Importância: Acessibilidade.
input { outline: none; }
Quando usar: Para remover borda de foco padrão.
outline: none pode afetar acessibilidade.
Dimensões

18. width

O que é: Largura do elemento.
Para que serve: Definir largura do elemento.
Importância: Controle de layout.
form { width: 400px; max-width: 50%; } .card { width: 400px; }
Quando usar: Para definir largura do elemento.
max-width limita largura máxima.

19. height

O que é: Altura do elemento.
Para que serve: Definir altura do elemento.
Importância: Controle de layout.
.cadastrar-button { height: 40px; } input { height: 40px; }
Quando usar: Para definir altura do elemento.
min-height e max-height também são úteis.
Interação

20. cursor

O que é: Tipo de cursor do mouse.
Para que serve: Indicar elemento interativo.
Importância: UX melhor.
.cadastrar-button { cursor: pointer; } button { cursor: pointer; }
Quando usar: Em elementos clicáveis.
pointer = mãozinha, default = seta padrão.

21. :hover

O que é: Pseudo-classe para estado hover.
Para que serve: Estilo ao passar mouse.
Importância: Feedback visual.
.cadastrar-button:hover { opacity: 0.5; } button:hover { opacity: 0.5; }
Quando usar: Para dar feedback ao passar mouse.
:hover só funciona em elementos interativos.

22. opacity

O que é: Transparência do elemento.
Para que serve: Criar efeito de transparência.
Importância: Feedback visual.
.cadastrar-button:hover { opacity: 0.5; } button:hover { opacity: 0.5; }
Quando usar: Para criar efeito de transparência.
0 = invisível, 1 = totalmente visível.
Texto

23. text-align

O que é: Alinhamento do texto.
Para que serve: Alinhar texto horizontalmente.
Importância: Layout do texto.
h1 { text-align: center; }
Quando usar: Para alinhar texto.
center = centralizado, left = esquerda, right = direita.

24. placeholder

O que é: Texto de placeholder do input.
Para que serve: Dar dica ao usuário.
Importância: UX melhor.
<input placeholder='Nome' /> <input placeholder='Idade' /> <input placeholder='Email' />
Quando usar: Para dar dica do que preencher.
Placeholder não substitui label.

📄 Arquivo index.html

1. Estrutura do index.html

O que é: Arquivo HTML principal do projeto.
Para que serve: Ponto de entrada da aplicação.
Importância: Onde React monta a aplicação.
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8" /> <link rel="icon" type="image/svg+xml" href="/vite.svg" /> <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <title>Vite + React</title; </head> <body> <div id="root"></div> <script type="module" src="/src/main.jsx"></script> </body> </html>
Quando usar: Criado automaticamente pelo Vite.
div com id="root" é onde React monta a aplicação.

2. DOCTYPE

O que é: Declaração do tipo de documento.
Para que serve: Informar navegador que é HTML5.
Importância: Renderização correta.
<!DOCTYPE html>
Quando usar: Primeira linha do arquivo HTML.
Sempre incluir no início do arquivo.

3. meta charset

O que é: Define codificação de caracteres.
Para que serve: Suportar caracteres especiais.
Importância: Acentuação correta.
<meta charset="UTF-8" />
Quando usar: Dentro da tag head.
UTF-8 suporta todos os caracteres.

4. meta viewport

O que é: Configura viewport para mobile.
Para que serve: Responsividade em dispositivos móveis.
Importância: Site responsivo.
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
Quando usar: Dentro da tag head.
Essencial para sites responsivos.

5. div id="root"

O que é: Elemento onde React monta a aplicação.
Para que serve: Ponto de montagem do React.
Importância: Onde a aplicação React aparece.
<div id="root"></div>
Quando usar: Dentro da tag body.
Deve ter exatamente id="root".

6. script type="module"

O que é: Script que usa módulos ES6.
Para que serve: Importar/exportar módulos.
Importância: Funcionalidades modernas de JavaScript.
<script type="module" src="/src/main.jsx"></script>
Quando usar: Para carregar arquivo principal do React.
type="module" habilita import/export.

📁 Estrutura do Projeto

1. Estrutura Completa

O que é: Organização de pastas e arquivos.
Para que serve: Organização do código.
Importância: Manutenibilidade e escalabilidade.
devclub-cadastro-usuarios/ ├── src/ │ ├── Home/ │ │ ├── index.jsx # Componente Home │ │ └── style.css # Estilos do Home │ ├── assets/ │ │ └── trash.svg # Imagem da lixeira │ ├── index.css # Estilos globais │ └── main.jsx # Arquivo principal ├── node_modules/ # Dependências ├── index.html # HTML principal ├── package.json # Configurações do projeto └── vite.config.js # Configurações do Vite
Quando usar: Estrutura padrão de projeto Vite + React.
src/ contém todo o código fonte.

2. Pasta src/

O que é: Pasta principal do código fonte.
Para que serve: Organizar todo o código da aplicação.
Importância: Separação de código e configurações.
src/ ├── Home/ ├── assets/ ├── index.css └── main.jsx
Quando usar: Todo o código da aplicação vai aqui.
Não modifique arquivos fora de src/ manualmente.

3. Pasta Home/

O que é: Pasta do componente Home.
Para que serve: Organizar código do componente.
Importância: Componentes auto-contidos.
Home/ ├── index.jsx # Lógica do componente └── style.css # Estilos do componente
Quando usar: Para cada componente principal.
index.jsx é o arquivo padrão importado.

4. Pasta assets/

O que é: Pasta de recursos estáticos.
Para que serve: Armazenar imagens, fontes, etc.
Importância: Organização de recursos.
assets/ └── trash.svg # Imagem da lixeira
Quando usar: Para armazenar imagens e outros recursos.
Vite otimiza imagens automaticamente.

5. package.json

O que é: Arquivo de configuração do projeto.
Para que serve: Define dependências e scripts.
Importância: Gerenciamento do projeto.
{ "name": "devclub-cadastro-usuarios", "version": "0.0.0", "type": "module", "scripts": { "dev": "vite", "build": "vite build", "preview": "vite preview" }, "dependencies": { "react": "^18.2.0", "react-dom": "^18.2.0" } }
Quando usar: Criado automaticamente pelo Vite.
Não modifique manualmente a menos que necessário.

6. node_modules/

O que é: Pasta de dependências instaladas.
Para que serve: Armazenar pacotes npm.
Importância: Dependências do projeto.
node_modules/ ├── react/ ├── react-dom/ ├── vite/ └── ...
Quando usar: Criado automaticamente pelo npm install.
Não modifique node_modules manualmente.
