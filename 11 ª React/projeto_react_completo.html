Comandos NPM

Terminal
# Criar projeto Vite npm create vite # Entrar no projeto cd nome-do-projeto # Instalar dependências npm install # Iniciar servidor de desenvolvimento npm run dev # Build para produção npm run build # Preview do build npm run preview
npm create vite - Cria um novo projeto Vite (ferramenta de build rápida)
cd nome-do-projeto - Navega para a pasta do projeto criado
npm install - Instala todas as dependências listadas no package.json
npm run dev - Inicia o servidor de desenvolvimento com hot reload (atualização automática)
npm run build - Compila o projeto para produção (cria versão otimizada)
npm run preview - Preview do build de produção localmente
