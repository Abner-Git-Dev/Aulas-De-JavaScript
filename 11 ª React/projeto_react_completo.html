📝 Observações Importantes

  • Componentes React sempre começam com letra maiúscula
  • Use className em vez de class no JSX
  • Use camelCase para eventos (onClick, onChange)
  • Sempre use key único ao usar map()
  • Importe imagens com caminho relativo correto
  • CSS modules ajudam a evitar conflitos de estilos
