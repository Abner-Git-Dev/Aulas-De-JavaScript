📚 React - Resumo Completo

Resumo dos conceitos de React aprendidos no projeto de cadastro de usuários.

1. O que é React?

O que faz: Biblioteca JavaScript para criar interfaces de usuário.
Quando usar: Para criar aplicações web modernas e interativas.
Importante: React é uma biblioteca, não um framework.
React usa componentes reutilizáveis
Atualizações automáticas da interface
Virtual DOM para performance

2. Criar Projeto Vite

O que faz: Cria um novo projeto React com Vite.
Quando usar: Para começar um novo projeto React.
Importante: Vite é mais rápido que Create React App.
npm create vite nome-do-projeto
cd nome-do-projeto
npm install
npm run dev
Resultado: Projeto React criado e servidor rodando

3. Componentes

O que faz: Blocos reutilizáveis de UI.
Quando usar: Para estruturar a aplicação.
Importante: Componentes começam com letra maiúscula.
function Home() {
  return (
    <div>Olá</div>
  );
}

export default Home;
Resultado: Componente Home criado

4. JSX

O que faz: Sintaxe que mistura HTML com JavaScript.
Quando usar: Para escrever a UI dos componentes.
Importante: className em vez de class.
return (
  <div className='container'>
    <h1>Título</h1>
  </div>
);
Resultado: HTML dentro de JavaScript

5. Importar Componentes

O que faz: Importa componentes de outros arquivos.
Quando usar: Para usar componentes criados em outros arquivos.
Importante: Caminho relativo correto.
import Home from './Home';
import Home from './pages/Home';
Resultado: Componente importado e pronto para uso

6. Renderizar Componente

O que faz: Renderiza o componente na página.
Quando usar: No arquivo principal (main.jsx).
Importante: Usa ReactDOM.createRoot.
import ReactDOM from 'react-dom/client';
import Home from './Home';

ReactDOM.createRoot(document.getElementById('root')).render(
  <Home />
);
Resultado: Componente renderizado na página

7. Props

O que faz: Passa dados entre componentes.
Quando usar: Para enviar dados de pai para filho.
Importante: Props são read-only.
// Pai:
<Usuario nome="Abner" idade={23} />

// Filho:
function Usuario(props) {
  return <p>{props.nome} - {props.idade}</p>;
}
Resultado: Dados passados entre componentes

8. State (useState)

O que faz: Gerencia estado interno do componente.
Quando usar: Para dados que mudam com o tempo.
Importante: useState retorna [valor, funçãoAtualizadora].
import { useState } from 'react';

function Home() {
  const [contador, setContador] = useState(0);

  return (
    <button onClick={() => setContador(contador + 1)}>
      {contador}
    </button>
  );
}
Resultado: Estado gerenciado no componente

9. map

O que faz: Itera sobre array e retorna elementos.
Quando usar: Para renderizar listas de componentes.
Importante: Sempre usar key único.
const users = [
  { id: 1, name: 'Abner' },
  { id: 2, name: 'Samira' }
];

{users.map(user => (
  <div key={user.id}>
    <p>{user.name}</p>
  </div>
))}
Resultado: Lista de usuários renderizada

10. CSS no React

O que faz: Estiliza componentes React.
Quando usar: Para dar estilo à interface.
Importante: Importar arquivo CSS no componente.
import './style.css';

// No JSX:
<div className='container'>
  <button className='cadastrar-button'>
    Cadastrar
  </button>
</div>
Resultado: Componente estilizado

11. Importar Imagens

O que faz: Importa imagens para usar no React.
Quando usar: Para usar imagens nos componentes.
Importante: Caminho relativo correto.
import Trash from '../../assets/trash.svg';

<img src={Trash} alt="trash" />
Resultado: Imagem exibida no componente

12. Eventos no React

O que faz: Manipula eventos de interação.
Quando usar: Para responder a cliques, inputs, etc.
Importante: camelCase (onClick, onChange).
<button onClick={() => alert('Clicou!')}>
  Clique
</button>

<input onChange={(e) => console.log(e.target.value)} />
Resultado: Eventos manipulados

13. Formulários no React

O que faz: Cria formulários interativos.
Quando usar: Para coletar dados do usuário.
Importante: Controlled inputs com state.
function Home() {
  const [nome, setNome] = useState('');

  return (
    <form>
      <input
        value={nome}
        onChange={(e) => setNome(e.target.value)}
      />
    </form>
  );
}
Resultado: Formulário controlado

14. Condicional Rendering

O que faz: Renderiza componentes condicionalmente.
Quando usar: Para mostrar/esconder elementos.
Importante: Usa operadores ternários ou &&.
// Ternário:
{isLoggedIn ? <Dashboard /> : <Login />}

// &&:
{showMessage && <p>Mensagem</p>}
Resultado: Renderização condicional

15. Fragment

O que faz: Agrupa elementos sem criar div extra.
Quando usar: Quando precisa retornar múltiplos elementos.
Importante: Usa <> ou React.Fragment.
return (
  <>
    <h1>Título</h1>
    <p>Texto</p>
  </>
);
Resultado: Múltiplos elementos sem div extra
