📚 DOM e Eventos em JavaScript - Guia Completo

Guia completo com todos os conceitos de DOM e eventos explicados detalhadamente.

1. O que é DOM?

O que faz: DOM (Document Object Model) é a representação do HTML como objetos JavaScript.
Quando usar: Sempre que precisar manipular elementos da página.
Importante: DOM permite que JavaScript interaja com a página web.

<h1 id="titulo">Olá Mundo</h1>


const titulo = document.getElementById('titulo');
console.log(titulo); // Elemento h1
Resultado: Elemento h1 selecionado

2. Selecionar por ID

O que faz: Seleciona um elemento único pelo seu ID.
Quando usar: Quando precisa selecionar um elemento específico.
Importante: ID deve ser único na página.
const elemento = document.getElementById('meuId');
console.log(elemento);
Resultado: Elemento com ID 'meuId'

3. Selecionar por Classe

O que faz: Seleciona elementos pela classe.
Quando usar: Quando precisa selecionar múltiplos elementos com mesma classe.
Importante: Retorna HTMLCollection (não array).
const elementos = document.getElementsByClassName('minhaClasse');
console.log(elementos); // HTMLCollection
Resultado: HTMLCollection com elementos da classe

4. Selecionar por Tag

O que faz: Seleciona elementos pelo nome da tag HTML.
Quando usar: Quando precisa selecionar todos os elementos de um tipo.
Importante: Retorna HTMLCollection.
const paragrafos = document.getElementsByTagName('p');
console.log(paragrafos); // HTMLCollection de parágrafos
Resultado: HTMLCollection de parágrafos

5. querySelector

O que faz: Seleciona o primeiro elemento que corresponde ao seletor CSS.
Quando usar: Forma mais flexível de selecionar elementos.
Importante: Usa sintaxe CSS (#id, .classe, tag, etc).
const elemento = document.querySelector('.minhaClasse');
const elemento2 = document.querySelector('#meuId');
const elemento3 = document.querySelector('p');
Resultado: Primeiro elemento que corresponde ao seletor

6. querySelectorAll

O que faz: Seleciona todos os elementos que correspondem ao seletor CSS.
Quando usar: Quando precisa selecionar múltiplos elementos.
Importante: Retorna NodeList (parecido com array).
const elementos = document.querySelectorAll('.minhaClasse');
console.log(elementos); // NodeList
Resultado: NodeList com todos os elementos

7. innerHTML

O que faz: Altera ou retorna o conteúdo HTML de um elemento.
Quando usar: Quando precisa inserir HTML dentro de um elemento.
Importante: Interpreta tags HTML (cuidado com XSS).
const div = document.querySelector('.minhaDiv');
div.innerHTML = '<strong>Texto em negrito</strong>';
Resultado: Texto em negrito

8. textContent

O que faz: Altera ou retorna apenas o texto de um elemento (sem HTML).
Quando usar: Quando precisa apenas de texto puro.
Importante: Mais seguro que innerHTML (não interpreta HTML).
const div = document.querySelector('.minhaDiv');
div.textContent = 'Texto puro';
// <strong>não</strong> será exibido literalmente
Resultado: Texto puro (sem interpretação HTML)

9. value

O que faz: Retorna ou altera o valor de inputs (text, number, etc).
Quando usar: Para pegar ou definir valores de formulários.
Importante: Funciona apenas em elementos de formulário.
const input = document.querySelector('.meuInput');
console.log(input.value); // Valor digitado
input.value = 'Novo valor'; // Define novo valor
Resultado: Valor do input

10. addEventListener

O que faz: Adiciona um "ouvinte" de eventos a um elemento.
Quando usar: Quando precisa executar código quando algo acontece.
Importante: Pode adicionar múltiplos listeners ao mesmo elemento.
const botao = document.querySelector('.botao');

botao.addEventListener('click', function() {
  console.log('Botão clicado!');
});
Resultado: 'Botão clicado!' quando o botão for clicado

11. preventDefault

O que faz: Impede o comportamento padrão de um evento.
Quando usar: Para impedir recarregamento de formulários, links, etc.
Importante: Essencial para formulários com JavaScript.
const form = document.querySelector('.form');

form.addEventListener('submit', function(evento) {
  evento.preventDefault(); // Impede recarregamento
  console.log('Formulário enviado sem recarregar');
});
Resultado: Formulário enviado sem recarregar a página

12. Evento Click

O que faz: Executa código quando elemento é clicado.
Quando usar: Para botões, links, etc.
Importante: Funciona em mouse e touch.
const botao = document.querySelector('.botao');

botao.addEventListener('click', function() {
  console.log('Clicado!');
});
Resultado: 'Clicado!' quando botão é clicado

13. Evento Submit

O que faz: Executa código quando formulário é enviado.
Quando usar: Para processar dados de formulários.
Importante: Sempre usar com preventDefault().
const form = document.querySelector('.form');

form.addEventListener('submit', function(evento) {
  evento.preventDefault();
  console.log('Processando formulário...');
});
Resultado: 'Processando formulário...' ao enviar

14. Evento Keyup

O que faz: Executa código quando tecla é solta.
Quando usar: Para validar inputs em tempo real.
Importante: Útil para campos de busca, validação, etc.
const input = document.querySelector('.input');

input.addEventListener('keyup', function() {
  console.log('Tecla solta:', input.value);
});
Resultado: Valor do input a cada tecla solta

15. Criar Elemento

O que faz: Cria um novo elemento HTML.
Quando usar: Para adicionar elementos dinamicamente.
Importante: Elemento precisa ser adicionado ao DOM.
const novoElemento = document.createElement('div');
novoElemento.textContent = 'Novo elemento';
document.body.appendChild(novoElemento);
Resultado: Novo div adicionado ao body

16. appendChild

O que faz: Adiciona um elemento como último filho de outro.
Quando usar: Para adicionar elementos ao DOM.
Importante: Move o elemento se já estiver no DOM.
const pai = document.querySelector('.pai');
const filho = document.createElement('div');
filho.textContent = 'Filho';
pai.appendChild(filho);
Resultado: Filho adicionado ao elemento pai

17. removeChild

O que faz: Remove um elemento filho do DOM.
Quando usar: Para remover elementos dinamicamente.
Importante: Precisa especificar o elemento a remover.
const pai = document.querySelector('.pai');
const filho = document.querySelector('.filho');
pai.removeChild(filho);
Resultado: Filho removido do elemento pai

18. classList.add

O que faz: Adiciona uma classe ao elemento.
Quando usar: Para estilizar ou identificar elementos.
Importante: Não duplica classes já existentes.
const elemento = document.querySelector('.elemento');
elemento.classList.add('novaClasse');
Resultado: Classe 'novaClasse' adicionada

19. classList.remove

O que faz: Remove uma classe do elemento.
Quando usar: Para remover estilos ou identificações.
Importante: Não dá erro se classe não existir.
const elemento = document.querySelector('.elemento');
elemento.classList.remove('minhaClasse');
Resultado: Classe 'minhaClasse' removida

20. classList.toggle

O que faz: Adiciona classe se não existe, remove se existe.
Quando usar: Para alternar estados (ativo/inativo).
Importante: Retorna true se adicionou, false se removeu.
const elemento = document.querySelector('.elemento');
elemento.classList.toggle('ativa'); // Alterna
Resultado: Classe 'ativa' alternada

21. setAttribute

O que faz: Define ou altera um atributo do elemento.
Quando usar: Para definir atributos como src, href, etc.
Importante: Sobrescreve atributos existentes.
const img = document.querySelector('img');
img.setAttribute('src', 'imagem.jpg');
img.setAttribute('alt', 'Descrição');
Resultado: Atributos src e alt definidos

22. getAttribute

O que faz: Retorna o valor de um atributo do elemento.
Quando usar: Para ler atributos como src, href, etc.
Importante: Retorna null se atributo não existir.
const img = document.querySelector('img');
const src = img.getAttribute('src');
console.log(src);
Resultado: Valor do atributo src

23. style

O que faz: Altera estilos CSS inline do elemento.
Quando usar: Para alterar estilos dinamicamente.
Importante: Propriedades CSS com hífen usam camelCase.
const elemento = document.querySelector('.elemento');
elemento.style.color = 'red';
elemento.style.backgroundColor = 'blue';
elemento.style.fontSize = '20px';
Resultado: Estilos inline aplicados
