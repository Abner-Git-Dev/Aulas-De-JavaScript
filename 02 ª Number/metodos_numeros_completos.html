📚 Métodos de Números em JavaScript - Guia Completo

Guia completo com todos os métodos de números e do objeto Math explicados detalhadamente.

1. toString()

O que faz: Converte um número para string.
Quando usar: Quando você precisa concatenar números com strings ou tratar números como texto.
Importante: Pode receber parâmetros para converter para diferentes bases (binário, hexadecimal, etc).
let num = 10;
console.log(num.toString()); // "10"
console.log(typeof num.toString()); // "string"
Resultado: "10" (string)
toString(2): Converte para binário (base 2)
toString(16): Converte para hexadecimal (base 16)
let num = 10;
console.log(num.toString(2)); // "1010" (binário)
console.log(num.toString(16)); // "a" (hexadecimal)

2. toFixed()

O que faz: Formata um número com um número fixo de casas decimais e retorna como string.
Quando usar: Quando você precisa exibir números com precisão específica (preços, medições, etc).
Importante: Arredonda o número e sempre retorna uma string.
let num = 10.5789;
console.log(num.toFixed(2)); // "10.58"
console.log(num.toFixed(0)); // "11"
console.log(num.toFixed(4)); // "10.5789"
Resultado: "10.58" (string com 2 casas decimais)
⚠️ IMPORTANTE: toFixed() sempre retorna string. Se precisar do número, use parseFloat() ou Number().
let num = 10.5789;
let resultado = parseFloat(num.toFixed(2));
console.log(resultado); // 10.58 (número)

3. Number.isInteger()

O que faz: Verifica se um valor é um número inteiro. Retorna true ou false.
Quando usar: Quando você precisa validar se um número não tem casas decimais.
Importante: Diferente de verificar se é número, verifica especificamente se é inteiro.
let num1 = 10;
let num2 = 10.5;

console.log(Number.isInteger(num1)); // true
console.log(Number.isInteger(num2)); // false
Resultado: true para 10, false para 10.5

4. Number.isNaN()

O que faz: Verifica se um valor é NaN (Not a Number). Retorna true se for NaN, false caso contrário.
Quando usar: Quando você precisa validar se uma operação matemática resultou em um valor inválido.
Importante: true significa que o valor é inválido (NaN), false significa que é um número válido.
let temp1 = 0 / 0; // NaN
let temp2 = 10 * '5'; // 50 (válido)

console.log(Number.isNaN(temp1)); // true (inválido)
console.log(Number.isNaN(temp2)); // false (válido)
Resultado: true para NaN, false para número válido
Exemplos que geram NaN: 0/0, parseInt('texto'), Math.sqrt(-1)

5. parseFloat()

O que faz: Converte uma string em um número de ponto flutuante (decimal).
Quando usar: Quando você precisa converter strings que representam números decimais.
Importante: Mantém as casas decimais, diferente de parseInt().
let str1 = "10.5";
let str2 = "10.999";
let str3 = "10";

console.log(parseFloat(str1)); // 10.5
console.log(parseFloat(str2)); // 10.999
console.log(parseFloat(str3)); // 10
Resultado: 10.5, 10.999, 10 (mantém decimais)
Diferença de parseInt: parseFloat("10.5") = 10.5, parseInt("10.5") = 10

6. parseInt()

O que faz: Converte uma string em um número inteiro.
Quando usar: Quando você precisa converter strings e remover casas decimais.
Importante: Remove as casas decimais (arredonda para baixo).
let str1 = "10.5";
let str2 = "10.999";
let str3 = "10";

console.log(parseInt(str1)); // 10
console.log(parseInt(str2)); // 10
console.log(parseInt(str3)); // 10
Resultado: 10, 10, 10 (remove decimais)
Diferença de parseFloat: parseInt("10.5") = 10, parseFloat("10.5") = 10.5

7. Number()

O que faz: Converte um valor em número. Pode converter strings, booleanos, etc.
Quando usar: Quando você precisa converter qualquer tipo para número.
Importante: Mais estrito que parseFloat/parseInt, retorna NaN se não conseguir converter.
let str1 = "10.5";
let str2 = "10";
let bool = true;

console.log(Number(str1)); // 10.5
console.log(Number(str2)); // 10
console.log(Number(bool)); // 1
Resultado: 10.5, 10, 1
Uso com toFixed: Number("10.58") = 10.58 (converte string de toFixed de volta para número)

8. Math.floor()

O que faz: Arredonda um número para baixo (para o menor inteiro mais próximo).
Quando usar: Quando você precisa remover casas decimais arredondando para baixo.
Importante: Sempre arredonda para baixo, independente do valor decimal.
let num1 = 10.7;
let num2 = 10.1;
let num3 = 10.9;
let num4 = 10.0;

console.log(Math.floor(num1)); // 10
console.log(Math.floor(num2)); // 10
console.log(Math.floor(num3)); // 10
console.log(Math.floor(num4)); // 10
Resultado: 10, 10, 10, 10 (sempre para baixo)

9. Math.ceil()

O que faz: Arredonda um número para cima (para o maior inteiro mais próximo).
Quando usar: Quando você precisa arredondar para cima.
Importante: Sempre arredonda para cima, mesmo se o decimal for pequeno.
let num1 = 10.1;
let num2 = 10.7;
let num3 = 10.9;
let num4 = 10.0;

console.log(Math.ceil(num1)); // 11
console.log(Math.ceil(num2)); // 11
console.log(Math.ceil(num3)); // 11
console.log(Math.ceil(num4)); // 10
Resultado: 11, 11, 11, 10 (sempre para cima, exceto se já for inteiro)

10. Math.round()

O que faz: Arredonda um número para o inteiro mais próximo.
Quando usar: Quando você precisa arredondar de forma padrão (para o mais próximo).
Importante: Arredonda para cima se decimal ≥ 0.5, para baixo se decimal < 0.5.
let num1 = 10.4;
let num2 = 10.5;
let num3 = 10.6;

console.log(Math.round(num1)); // 10
console.log(Math.round(num2)); // 11
console.log(Math.round(num3)); // 11
Resultado: 10, 11, 11 (arredonda para o mais próximo)

11. Math.max()

O que faz: Retorna o maior número entre os argumentos fornecidos.
Quando usar: Quando você precisa encontrar o valor máximo em uma lista de números.
Importante: Pode receber múltiplos argumentos separados por vírgula.
console.log(Math.max(1, 2, 3, 4, 5)); // 5
console.log(Math.max(10, -10, 100, 50)); // 100
console.log(Math.max(-10, -50, -1)); // -1
Resultado: 5, 100, -1 (maior número de cada lista)

12. Math.min()

O que faz: Retorna o menor número entre os argumentos fornecidos.
Quando usar: Quando você precisa encontrar o valor mínimo em uma lista de números.
Importante: Pode receber múltiplos argumentos separados por vírgula.
console.log(Math.min(1, 2, 3, 4, 5)); // 1
console.log(Math.min(10, -10, 100, 50)); // -10
console.log(Math.min(-10, -50, -1)); // -50
Resultado: 1, -10, -50 (menor número de cada lista)

13. Math.random()

O que faz: Gera um número aleatório entre 0 (inclusive) e 1 (exclusivo).
Quando usar: Quando você precisa gerar números aleatórios para jogos, testes, simulações.
Importante: Sempre retorna entre 0 e 1. Para outros intervalos, use a fórmula.
console.log(Math.random()); // 0.123... (entre 0 e 1)
console.log(Math.random()); // 0.789... (entre 0 e 1)
console.log(Math.random()); // 0.456... (entre 0 e 1)
Resultado: Números aleatórios entre 0 e 1
Fórmula para intervalo: Math.round(Math.random() * (max - min) + min)
// Número aleatório entre 5 e 10
const aleatorio = Math.round(Math.random() * (10 - 5) + 5);
console.log(aleatorio); // 5, 6, 7, 8, 9 ou 10

14. Math.pow()

O que faz: Calcula a potência de um número (base elevada ao expoente).
Quando usar: Quando você precisa calcular potências matemáticas.
Importante: Primeiro argumento é a base, segundo é o expoente.
console.log(Math.pow(2, 3)); // 8 (2³)
console.log(Math.pow(2, 10)); // 1024 (2¹⁰)
console.log(Math.pow(3, 2)); // 9 (3²)
Resultado: 8, 1024, 9
Operador moderno: 2 ** 3 = 8 (mesmo que Math.pow(2, 3))

15. Operador ** (Potência)

O que faz: Calcula potência de forma mais moderna e legível que Math.pow().
Quando usar: Quando você precisa calcular potências (preferível ao Math.pow()).
Importante: Sintaxe mais limpa e moderna (ES6+).
console.log(2 ** 3); // 8 (2³)
console.log(2 ** 10); // 1024 (2¹⁰)
console.log(3 ** 2); // 9 (3²)
Resultado: 8, 1024, 9
Raiz quadrada: num ** 0.5 ou num ** (1/2)
let num = 9;
console.log(num ** 0.5); // 3 (raiz quadrada)
console.log(num ** (1/2)); // 3 (raiz quadrada)

16. Math.sqrt()

O que faz: Calcula a raiz quadrada de um número.
Quando usar: Quando você precisa calcular raiz quadrada.
Importante: Retorna NaN se o número for negativo.
console.log(Math.sqrt(9)); // 3
console.log(Math.sqrt(16)); // 4
console.log(Math.sqrt(25)); // 5
Resultado: 3, 4, 5
Alternativa: num ** 0.5 (mesmo resultado)
