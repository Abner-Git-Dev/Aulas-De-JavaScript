Async e Await - Explicação Detalhada

O que é async/await?

async/await é uma sintaxe do JavaScript para trabalhar com código assíncrono de forma mais legível, similar a código síncrono.

async

O que é: Palavra-chave que marca uma função como assíncrona
O que faz: Permite usar await dentro da função
O que retorna: Sempre retorna uma Promise
Quando usar: Quando a função tem operações assíncronas
async function criarUsuario() { // código assíncrono aqui } app.post('/usuarios', async (req, res) => { // função assíncrona para rota POST })

await

O que é: Palavra-chave que pausa a execução até uma Promise resolver
O que faz: Espera uma operação assíncrona terminar antes de continuar
Onde usar: Dentro de funções marcadas com async
Quando usar: Para operações que demoram (banco de dados, API, arquivos)
const usuario = await prisma.user.create() // O código para aqui até prisma.user.create() terminar console.log(usuario) // só executa depois que terminar

Por que usar async/await?

1. Operações de banco de dados são assíncronas
- prisma.user.create() retorna uma Promise
- prisma.user.findMany() retorna uma Promise
- Precisamos esperar essas operações terminarem
2. Código mais legível
- Sem async/await: .then() e .catch() (callback hell)
- Com async/await: Código parece síncrono
3. Evita erros
- Sem await: O código continua antes da operação terminar
- Com await: Garante que a operação terminou

Fluxo de Execução com await

1. Código chega no await
2. Execução PAUSA
3. Operação assíncrona roda em segundo plano
4. Quando termina, execução RETOMA
5. Código continua normalmente
console.log('1') await prisma.user.create() // pausa aqui console.log('2') // só executa depois que terminar Saída: 1 (espera banco de dados) 2

Try/Catch com async/await

Para tratar erros em funções async:
app.post('/usuarios', async (req, res) => { try { const user = await prisma.user.create({ data: req.body }) res.status(201).json(user) } catch (error) { res.status(500).json({ erro: error.message }) } })
try: Código que pode dar erro
catch: Código que executa se der erro

Fluxo Completo da API com Prisma

Fluxo de Criação (POST) com Prisma

1. Cliente envia POST para /usuarios com dados JSON
2. Middleware express.json() converte JSON para objeto
3. Função assíncrona da rota POST é executada
4. await prisma.user.create() salva usuário no MongoDB
5. Código pausa até operação do banco terminar
6. res.status(201).json() envia resposta ao cliente

Fluxo de Leitura (GET) com Prisma

1. Cliente envia GET para /usuarios
2. Função assíncrona da rota GET é executada
3. await prisma.user.findMany() busca usuários no MongoDB
4. Código pausa até operação do banco terminar
5. res.status(200).json() envia array de usuários ao cliente
