ASYNC E AWAIT - EXPLICAÇÃO DETALHADA
================================================================================

O QUE É ASYNC/AWAIT?
================================================================================

async/await é uma sintaxe do JavaScript para trabalhar com código assíncrono 
de forma mais legível, similar a código síncrono.


ASYNC
================================================================================

- O que é: Palavra-chave que marca uma função como assíncrona
- O que faz: Permite usar await dentro da função
- O que retorna: Sempre retorna uma Promise
- Quando usar: Quando a função tem operações assíncronas

Exemplo:
async function criarUsuario() {
  // código assíncrono aqui
}

const app.post('/usuarios', async (req, res) => {
  // função assíncrona para rota POST
})


AWAIT
================================================================================

- O que é: Palavra-chave que pausa a execução até uma Promise resolver
- O que faz: Espera uma operação assíncrona terminar antes de continuar
- Onde usar: Dentro de funções marcadas com async
- Quando usar: Para operações que demoram (banco de dados, API, arquivos)

Exemplo:
const usuario = await prisma.user.create()
// O código para aqui até prisma.user.create() terminar
console.log(usuario) // só executa depois que terminar


POR QUE USAR ASYNC/AWAIT?
================================================================================

1. Operações de banco de dados são assíncronas
   - prisma.user.create() retorna uma Promise
   - prisma.user.findMany() retorna uma Promise
   - Precisamos esperar essas operações terminarem

2. Código mais legível
   - Sem async/await: .then() e .catch() (callback hell)
   - Com async/await: Código parece síncrono

3. Evita erros
   - Sem await: O código continua antes da operação terminar
   - Com await: Garante que a operação terminou


EXEMPLO SEM ASYNC/AWAIT (ANTIGO)
================================================================================

app.post('/usuarios', (req, res) => {
  prisma.user.create({
    data: req.body
  })
  .then(user => {
    res.status(201).json(user)
  })
  .catch(error => {
    res.status(500).json({ erro: error.message })
  })
})


EXEMPLO COM ASYNC/AWAIT (MODERNO)
================================================================================

app.post('/usuarios', async (req, res) => {
  try {
    const user = await prisma.user.create({
      data: req.body
    })
    res.status(201).json(user)
  } catch (error) {
    res.status(500).json({ erro: error.message })
  }
})


FLUXO DE EXECUÇÃO COM AWAIT
================================================================================

1. Código chega no await
2. Execução PAUSA
3. Operação assíncrona roda em segundo plano
4. Quando termina, execução RETOMA
5. Código continua normalmente

Exemplo:
console.log('1')
await prisma.user.create() // pausa aqui
console.log('2') // só executa depois que terminar

Saída:
1
(espera banco de dados)
2


ERROS COMUNS SEM AWAIT
================================================================================

1. Dados undefined
   - Se não usar await, a variável fica undefined
   - Exemplo: const user = prisma.user.create() // user = undefined

2. Erro de concorrência
   - Código continua antes da operação terminar
   - Pode causar erros inesperados

3. Promise pendente
   - A Promise nunca é resolvida
   - Código pode travar


TRY/CATCH COM ASYNC/AWAIT
================================================================================

Para tratar erros em funções async:

app.post('/usuarios', async (req, res) => {
  try {
    const user = await prisma.user.create({
      data: req.body
    })
    res.status(201).json(user)
  } catch (error) {
    res.status(500).json({ erro: error.message })
  }
})

- try: Código que pode dar erro
- catch: Código que executa se der erro


PRISMA CLIENT - MÉTODOS PRINCIPAIS
================================================================================

prisma.user.create()
- Cria um novo registro
- Retorna o registro criado
- É assíncrono (precisa de await)

prisma.user.findMany()
- Busca todos os registros
- Retorna array com todos
- É assíncrono (precisa de await)

prisma.user.findUnique()
- Busca um registro específico
- Usa where para filtrar
- É assíncrono (precisa de await)

prisma.user.update()
- Atualiza um registro
- Usa where e data
- É assíncrono (precisa de await)

prisma.user.delete()
- Deleta um registro
- Usa where para filtrar
- É assíncrono (precisa de await)
