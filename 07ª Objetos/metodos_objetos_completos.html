📚 Objetos em JavaScript - Guia Completo

Guia completo com todos os conceitos de objetos explicados detalhadamente.

1. Criação de Objeto

O que faz: Cria um objeto literal usando chaves `{}`.
Quando usar: Para agrupar dados relacionados em uma estrutura.
Importante: Objetos são coleções de pares chave-valor.
const pessoa1 = {
  nome: 'Abner'
};

console.log(pessoa1); // {nome: 'Abner'}
Resultado: {nome: 'Abner'}

2. Acesso a Propriedades

O que faz: Acessa o valor de uma propriedade do objeto.
Quando usar: Para ler ou modificar valores do objeto.
Importante: Use ponto `.` para propriedades comuns, colchetes `[]` para propriedades dinâmicas.
const pessoa1 = {
  nome: 'Abner'
};

console.log(pessoa1.nome); // 'Abner'
console.log(pessoa1['nome']); // 'Abner'
Resultado: 'Abner', 'Abner'

3. Múltiplas Propriedades

O que faz: Objeto com várias propriedades.
Quando usar: Para representar entidades complexas.
Importante: Separe propriedades com vírgula.
const pessoa = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23
};

console.log(pessoa.nome); // 'Abner'
console.log(pessoa.sobrenome); // 'Silva'
console.log(pessoa.idade); // 23
Resultado: 'Abner', 'Silva', 23

4. Função Factory

O que faz: Função que cria e retorna objetos.
Quando usar: Para criar múltiplos objetos similares.
Importante: Reutiliza código para criar objetos.
function criaPessoa(nome, sobrenome, idade) {
  return {
    nome: nome,
    sobrenome: sobrenome,
    idade: idade
  };
}

const pessoa2 = criaPessoa('Samira', 'Silva', 23);
const pessoa3 = criaPessoa('Abner', 'Furutani', 23);

console.log(pessoa2.nome); // 'Samira'
Resultado: 'Samira'

5. Shorthand Property Names (ES6)

O que faz: Simplifica quando nome da propriedade é igual ao da variável.
Quando usar: Para código mais limpo e moderno.
Importante: Funciona apenas quando nome da propriedade = nome da variável.
function criaPessoa(nome, sobrenome, idade) {
  return { nome, sobrenome, idade };
}

const pessoa = criaPessoa('Abner', 'Silva', 23);
console.log(pessoa.nome); // 'Abner'
Resultado: 'Abner'
Forma tradicional: { nome: nome }
Forma moderna: { nome }

6. Métodos em Objetos

O que faz: Funções dentro de objetos que executam ações.
Quando usar: Para adicionar comportamento aos objetos.
Importante: Métodos podem acessar e modificar propriedades do objeto.
const pessoa5 = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23,

  fala() {
    console.log('Ola mundo!');
  }
};

pessoa5.fala(); // 'Ola mundo!'
Resultado: 'Ola mundo!'

7. This

O que faz: `this` se refere ao próprio objeto.
Quando usar: Para acessar propriedades do objeto dentro de métodos.
Importante: Permite que métodos acessem dados do próprio objeto.
const pessoa5 = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23,

  fala() {
    console.log(`${this.nome} ${this.sobrenome} ${this.idade}`);
  }
};

pessoa5.fala(); // 'Abner Silva 23'
Resultado: 'Abner Silva 23'
⚠️ IMPORTANTE: `this` se refere ao objeto que está chamando o método.

8. Modificando Propriedades com Métodos

O que faz: Métodos que alteram valores das propriedades.
Quando usar: Para encapsular lógica de modificação.
Importante: Use `this` para acessar e modificar propriedades.
const pessoa5 = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23,

  fala() {
    console.log(`${this.nome} ${this.sobrenome} ${this.idade} está falando oi....`);
  },

  incrementaIdade() {
    this.idade++;
  }
};

pessoa5.fala(); // 'Abner Silva 23 está falando oi....'
pessoa5.incrementaIdade();
console.log(pessoa5.idade); // 24
Resultado: 'Abner Silva 23 está falando oi....', 24

9. Adicionando Propriedades Dinamicamente

O que faz: Adiciona novas propriedades após a criação do objeto.
Quando usar: Quando precisa adicionar dados em tempo de execução.
Importante: Objetos em JavaScript são mutáveis.
const pessoa = {
  nome: 'Abner'
};

pessoa.sobrenome = 'Silva';
pessoa.idade = 23;

console.log(pessoa); // {nome: 'Abner', sobrenome: 'Silva', idade: 23}
Resultado: {nome: 'Abner', sobrenome: 'Silva', idade: 23}

10. Deletando Propriedades

O que faz: Remove uma propriedade do objeto.
Quando usar: Quando não precisa mais de uma propriedade.
Importante: Use o operador `delete`.
const pessoa = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23
};

delete pessoa.idade;
console.log(pessoa); // {nome: 'Abner', sobrenome: 'Silva'}
Resultado: {nome: 'Abner', sobrenome: 'Silva'}

11. Verificando Propriedades

O que faz: Verifica se uma propriedade existe no objeto.
Quando usar: Para evitar erros ao acessar propriedades inexistentes.
Importante: Use `in` ou `hasOwnProperty()`.
const pessoa = {
  nome: 'Abner',
  sobrenome: 'Silva'
};

console.log('nome' in pessoa); // true
console.log('idade' in pessoa); // false
console.log(pessoa.hasOwnProperty('nome')); // true
Resultado: true, false, true

12. Listando Propriedades

O que faz: Obtém todas as chaves ou valores do objeto.
Quando usar: Para iterar sobre as propriedades do objeto.
Importante: Use `Object.keys()`, `Object.values()` ou `Object.entries()`.
const pessoa = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23
};

console.log(Object.keys(pessoa)); // ['nome', 'sobrenome', 'idade']
console.log(Object.values(pessoa)); // ['Abner', 'Silva', 23]
console.log(Object.entries(pessoa)); // [['nome', 'Abner'], ['sobrenome', 'Silva'], ['idade', 23]]
Resultado: ['nome', 'sobrenome', 'idade'], ['Abner', 'Silva', 23], [['nome', 'Abner'], ['sobrenome', 'Silva'], ['idade', 23]]

13. Objeto como Parâmetro

O que faz: Passa objetos como parâmetros de funções.
Quando usar: Para passar dados complexos para funções.
Importante: Objetos são passados por referência.
function apresentar(pessoa) {
  console.log(`${pessoa.nome} tem ${pessoa.idade} anos`);
}

const pessoa = {
  nome: 'Abner',
  idade: 23
};

apresentar(pessoa); // 'Abner tem 23 anos'
Resultado: 'Abner tem 23 anos'

14. Destructuring de Objetos

O que faz: Extrai propriedades de objetos para variáveis.
Quando usar: Para código mais limpo e legível.
Importante: Forma moderna de extrair dados de objetos.
const pessoa = {
  nome: 'Abner',
  sobrenome: 'Silva',
  idade: 23
};

const { nome, sobrenome, idade } = pessoa;

console.log(nome); // 'Abner'
console.log(sobrenome); // 'Silva'
console.log(idade); // 23
Resultado: 'Abner', 'Silva', 23
