📚 Funções em JavaScript - Guia Completo

Guia completo com todos os tipos de funções e conceitos explicados detalhadamente.

1. Função Tradicional (Named Function)

O que faz: Declara uma função com nome usando a palavra-chave `function`.
Quando usar: Quando você precisa criar uma função reutilizável com nome.
Importante: Pode ser chamada antes de ser declarada (hoisting).
function saudacao(nome) {
  console.log(`Bom dia ${nome}`);
}

saudacao('Abner'); // 'Bom dia Abner'
saudacao('Samira'); // 'Bom dia Samira'
Resultado: 'Bom dia Abner', 'Bom dia Samira'

2. Função com Return

O que faz: Retorna um valor que pode ser armazenado em uma variável.
Quando usar: Quando você precisa usar o resultado da função em outras operações.
Importante: `return` encerra a função e retorna o valor especificado.
function soma(x, y) {
  const resultado = x + y;
  return resultado;
}

const resultado = soma(2, 2);
console.log(resultado); // 4
Resultado: 4
Diferença: Funções sem return apenas executam, funções com return retornam valores.

3. Parâmetros

O que faz: Define valores que a função recebe quando é chamada.
Quando usar: Quando você precisa que a função trabalhe com dados diferentes.
Importante: Se não passar parâmetros, eles serão `undefined`.
function soma(x, y) {
  return x + y;
}

console.log(soma(2, 3)); // 5
console.log(soma(10, 5)); // 15
console.log(soma()); // NaN (undefined + undefined)
Resultado: 5, 15, NaN

4. Parâmetros Padrão (Default Parameters)

O que faz: Define valores padrão para parâmetros caso não sejam passados.
Quando usar: Quando você quer que a função tenha valores de fallback.
Importante: Evita `undefined` quando parâmetros não são passados.
function soma(x = 1, y = 1) {
  return x + y;
}

console.log(soma()); // 2 (1 + 1)
console.log(soma(4)); // 5 (4 + 1)
console.log(soma(4, 3)); // 7 (4 + 3)
Resultado: 2, 5, 7

5. Função Anônima (Anonymous Function)

O que faz: Cria uma função sem nome e atribui a uma variável.
Quando usar: Quando você precisa passar funções como parâmetro ou atribuir a variáveis.
Importante: Recomendado usar ponto e vírgula no final da atribuição.
const raiz = function(n) {
  return n ** 0.5;
};

console.log(raiz(9)); // 3
console.log(raiz(16)); // 4
Resultado: 3, 4

6. Arrow Function (Função Flecha)

O que faz: Forma moderna e concisa de escrever funções em JavaScript (ES6).
Quando usar: Para funções curtas e callbacks. É a forma mais moderna.
Importante: Não tem seu próprio `this`, o que pode ser vantagem ou desvantagem.
const raiz = (n) => {
  return n ** 0.5;
};

console.log(raiz(9)); // 3
Resultado: 3

7. Arrow Function Simplificada

O que faz: Forma mais concisa de arrow function quando tem apenas uma linha.
Quando usar: Para funções simples de uma linha.
Importante: Remove chaves e `return` implícito.
const raiz = (n) => n ** 0.5;

console.log(raiz(9)); // 3
console.log(raiz(16)); // 4
Resultado: 3, 4
Regras de simplificação:
- 1 parâmetro: pode remover parênteses
- 1 linha: pode remover chaves e return
- 0 parâmetros: precisa de parênteses vazios
- +1 parâmetros: precisa de parênteses

8. Arrow Function com 1 Parâmetro (Sem Parênteses)

O que faz: Remove parênteses quando há apenas um parâmetro.
Quando usar: Para funções com apenas um parâmetro.
Importante: Apenas quando há exatamente um parâmetro.
const raiz = n => n ** 0.5;
const dobro = n => n * 2;

console.log(raiz(9)); // 3
console.log(dobro(5)); // 10
Resultado: 3, 10

9. Arrow Function Sem Parâmetros

O que faz: Arrow function que não recebe parâmetros.
Quando usar: Para funções que não precisam de dados externos.
Importante: Precisa usar parênteses vazios `()`.
const saudacao = () => 'Olá';
const numeroAleatorio = () => Math.random();

console.log(saudacao()); // 'Olá'
console.log(numeroAleatorio()); // número aleatório
Resultado: 'Olá', número aleatório

10. Arrow Function com Múltiplos Parâmetros

O que faz: Arrow function com dois ou mais parâmetros.
Quando usar: Para funções que precisam de múltiplos dados.
Importante: Precisa usar parênteses.
const soma = (a, b) => a + b;
const multiplicar = (a, b, c) => a * b * c;

console.log(soma(2, 3)); // 5
console.log(multiplicar(2, 3, 4)); // 24
Resultado: 5, 24

11. Concatenação de Strings em Funções

O que faz: Quando você passa strings para uma função que usa `+`, ocorre concatenação.
Quando usar: Cuidado ao passar strings para funções matemáticas.
Importante: Use `Number()` ou `parseFloat()` para converter strings em números.
function soma(x, y) {
  return x + y;
}

console.log(soma('Abner', 'Silva')); // 'AbnerSilva' (concatenação)
console.log(soma(Number('5'), Number('3'))); // 8 (soma matemática)
Resultado: 'AbnerSilva', 8
⚠️ IMPORTANTE: O operador `+` concatena strings e soma números. Sempre converta strings para números se quiser operações matemáticas.

12. Função com Múltiplas Linhas

O que faz: Funções que executam múltiplas operações.
Quando usar: Quando a lógica é mais complexa.
Importante: Precisa usar chaves e `return` explícito.
function calcular(x, y) {
  const soma = x + y;
  const multiplicacao = x * y;
  return {
    soma,
    multiplicacao
  };
}

console.log(calcular(2, 3)); // {soma: 5, multiplicacao: 6}
Resultado: {soma: 5, multiplicacao: 6}

13. Hoisting

O que faz: Funções tradicionais podem ser chamadas antes de serem declaradas.
Quando usar: Entender o comportamento do JavaScript.
Importante: Arrow functions e funções anônimas não têm hoisting.
// Chamando antes de declarar
saudacao('Abner'); // Funciona!

function saudacao(nome) {
  console.log(`Olá ${nome}`);
}
Resultado: 'Olá Abner' (funciona por causa do hoisting)
Não funciona com: const saudacao = () => ... (dá erro ReferenceError)
