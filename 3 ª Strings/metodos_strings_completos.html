Métodos Completos de Strings em JavaScript

Guia completo com explicação detalhada de cada método de strings em JavaScript.

1. length

O que faz: Retorna o número de caracteres (tamanho) da string.
Quando usar: Quando você precisa saber quantos caracteres tem uma string.
Importante: Conta espaços em branco e caracteres especiais. Começa do 1, não do 0.
let texto = "JavaScript";
console.log(texto.length); // 10

2. charAt()

O que faz: Retorna o caractere em uma posição específica (índice).
Quando usar: Quando você precisa pegar uma letra específica da string.
Importante: Os índices começam em 0. Se o índice não existir, retorna string vazia.
let texto = "JavaScript";
console.log(texto.charAt(0)); // "J" (primeira letra)
console.log(texto.charAt(4)); // "S"
console.log(texto.charAt(10)); // "" (vazio, não existe)

3. charCodeAt()

O que faz: Retorna o código Unicode (número) do caractere em uma posição específica.
Quando usar: Quando você precisa do código numérico de um caractere.
Importante: Útil para comparações ou operações com códigos de caracteres.
let texto = "A";
console.log(texto.charCodeAt(0)); // 65 (código Unicode de "A")

4. concat()

O que faz: Junta (concatena) duas ou mais strings em uma única string.
Quando usar: Quando você precisa combinar textos.
Importante: Hoje em dia é mais comum usar template literals (`${}`) ou o operador `+`.
let texto1 = "Olá";
let texto2 = "Mundo";
console.log(texto1.concat(" ", texto2)); // "Olá Mundo"
console.log(texto1 + " " + texto2); // "Olá Mundo" (mais comum)

5. indexOf()

O que faz: Retorna o índice da PRIMEIRA ocorrência de um texto dentro da string.
Quando usar: Quando você precisa saber onde um texto aparece pela primeira vez.
Importante: Se não encontrar, retorna -1. Diferencia maiúsculas de minúsculas.
let texto = "JavaScript é incrível";
console.log(texto.indexOf("a")); // 1 (primeiro "a")
console.log(texto.indexOf("é")); // 11
console.log(texto.indexOf("z")); // -1 (não existe)

6. lastIndexOf()

O que faz: Retorna o índice da ÚLTIMA ocorrência de um texto dentro da string.
Quando usar: Quando você precisa saber onde um texto aparece pela última vez.
Importante: Se não encontrar, retorna -1. Busca de trás para frente.
let texto = "JavaScript é incrível";
console.log(texto.lastIndexOf("a")); // 14 (último "a")
console.log(texto.lastIndexOf("i")); // 18

7. includes()

O que faz: Verifica se um texto está contido na string. Retorna true ou false.
Quando usar: Quando você precisa saber se um texto existe dentro de outro.
Importante: Diferencia maiúsculas de minúsculas. Mais moderno que indexOf.
let texto = "JavaScript é incrível";
console.log(texto.includes("Java")); // true
console.log(texto.includes("python")); // false

8. startsWith()

O que faz: Verifica se a string COMEÇA com um texto específico. Retorna true ou false.
Quando usar: Quando você precisa validar se um texto começa de uma certa forma.
Importante: Diferencia maiúsculas de minúsculas.
let texto = "JavaScript教程";
console.log(texto.startsWith("Java")); // true
console.log(texto.startsWith("java")); // false (maiúscula diferente)

9. endsWith()

O que faz: Verifica se a string TERMINA com um texto específico. Retorna true ou false.
Quando usar: Quando você precisa validar se um texto termina de uma certa forma.
Importante: Diferencia maiúsculas de minúsculas.
let texto = "arquivo.pdf";
console.log(texto.endsWith(".pdf")); // true
console.log(texto.endsWith(".doc")); // false

10. slice()

O que faz: Extrai uma parte da string e retorna uma nova string.
Quando usar: Quando você precisa pegar um pedaço específico do texto.
Importante: Aceita índices negativos (conta de trás para frente). Não altera a string original.
let texto = "JavaScript";
console.log(texto.slice(0, 4)); // "Java" (do índice 0 até 4)
console.log(texto.slice(4)); // "Script" (do índice 4 até o fim)
console.log(texto.slice(-6)); // "Script" (últimos 6 caracteres)
console.log(texto.slice(-6, -3)); // "Scr"

11. substring()

O que faz: Similar ao slice(), extrai uma parte da string.
Quando usar: Quando você precisa pegar um pedaço do texto.
Importante: NÃO aceita índices negativos. Se o primeiro parâmetro for maior que o segundo, ele inverte automaticamente.
let texto = "JavaScript";
console.log(texto.substring(0, 4)); // "Java"
console.log(texto.substring(4, 0)); // "Java" (inverte automaticamente)
console.log(texto.substring(-3)); // "JavaScript" (ignora negativo)

12. substr()

O que faz: Extrai uma parte da string a partir de uma posição e com um comprimento específico.
Quando usar: Quando você precisa pegar um pedaço definindo o tamanho.
Importante: Está sendo descontinuado (obsoleto). Prefira usar slice() ou substring().
let texto = "JavaScript";
console.log(texto.substr(0, 4)); // "Java" (começa em 0, pega 4 caracteres)
console.log(texto.substr(4, 6)); // "Script" (começa em 4, pega 6 caracteres)

13. replace()

O que faz: Substitui um texto por outro na string.
Quando usar: Quando você precisa trocar palavras ou caracteres.
Importante: Por padrão, substitui apenas a PRIMEIRA ocorrência. Para substituir todas, use regex com flag /g.
let texto = "JavaScript é incrível, JavaScript é poderoso";
console.log(texto.replace("JavaScript", "JS")); // "JS é incrível, JavaScript é poderoso" (só a primeira)
console.log(texto.replace(/JavaScript/g, "JS")); // "JS é incrível, JS é poderoso" (todas)

14. replaceAll()

O que faz: Substitui TODAS as ocorrências de um texto por outro.
Quando usar: Quando você precisa trocar todas as ocorrências sem usar regex.
Importante: Método mais moderno (ES2021). Funciona como replace() com /g.
let texto = "JavaScript é incrível, JavaScript é poderoso";
console.log(texto.replaceAll("JavaScript", "JS")); // "JS é incrível, JS é poderoso"

15. toUpperCase()

O que faz: Converte toda a string para letras MAIÚSCULAS.
Quando usar: Quando você precisa normalizar texto para comparações ou exibição.
Importante: Não altera a string original, retorna uma nova string.
let texto = "JavaScript";
console.log(texto.toUpperCase()); // "JAVASCRIPT"

16. toLowerCase()

O que faz: Converte toda a string para letras MINÚSCULAS.
Quando usar: Quando você precisa normalizar texto para comparações ou exibição.
Importante: Não altera a string original, retorna uma nova string.
let texto = "JavaScript";
console.log(texto.toLowerCase()); // "javascript"

17. toLocaleUpperCase()

O que faz: Converte para maiúsculas considerando o idioma/local do usuário.
Quando usar: Quando você precisa respeitar regras específicas de idiomas (como turco, alemão).
Importante: Para português, funciona igual ao toUpperCase().
let texto = "javascript";
console.log(texto.toLocaleUpperCase()); // "JAVASCRIPT"

18. toLocaleLowerCase()

O que faz: Converte para minúsculas considerando o idioma/local do usuário.
Quando usar: Quando você precisa respeitar regras específicas de idiomas.
Importante: Para português, funciona igual ao toLowerCase().
let texto = "JAVASCRIPT";
console.log(texto.toLocaleLowerCase()); // "javascript"

19. trim()

O que faz: Remove espaços em branco do INÍCIO e do FIM da string.
Quando usar: Quando você precisa limpar inputs de formulários ou textos com espaços extras.
Importante: Não remove espaços no meio da string.
let texto = " JavaScript ";
console.log(texto.trim()); // "JavaScript" (sem espaços nas pontas)

20. trimStart()

O que faz: Remove espaços em branco apenas do INÍCIO da string.
Quando usar: Quando você precisa limpar apenas o começo do texto.
Importante: Também conhecido como trimLeft().
let texto = " JavaScript ";
console.log(texto.trimStart()); // "JavaScript " (sem espaços no início)

21. trimEnd()

O que faz: Remove espaços em branco apenas do FIM da string.
Quando usar: Quando você precisa limpar apenas o final do texto.
Importante: Também conhecido como trimRight().
let texto = " JavaScript ";
console.log(texto.trimEnd()); // " JavaScript" (sem espaços no final)

22. padStart()

O que faz: Adiciona caracteres no INÍCIO da string até atingir um tamanho específico.
Quando usar: Para formatar números (001, 002), alinhar textos, criar IDs.
Importante: Se a string já for maior que o tamanho, não faz nada.
let texto = "5";
console.log(texto.padStart(3, "0")); // "005" (completa com zeros até ter 3 caracteres)
console.log(texto.padStart(5, "*")); // "****5"

23. padEnd()

O que faz: Adiciona caracteres no FIM da string até atingir um tamanho específico.
Quando usar: Para alinhar textos à direita, formatar tabelas.
Importante: Se a string já for maior que o tamanho, não faz nada.
let texto = "5";
console.log(texto.padEnd(3, "0")); // "500" (completa com zeros até ter 3 caracteres)
console.log(texto.padEnd(5, "*")); // "5****"

24. split()

O que faz: Divide a string em um array baseado em um separador.
Quando usar: Quando você precisa separar palavras, dados CSV, processar texto.
Importante: Se não encontrar o separador, retorna array com a string inteira. Pode limitar o número de divisões.
let texto = "JavaScript é incrível";
console.log(texto.split(" ")); // ["JavaScript", "é", "incrível"]
console.log(texto.split(" ", 2)); // ["JavaScript", "é"] (limita a 2 divisões)

25. repeat()

O que faz: Repete a string um número específico de vezes.
Quando usar: Para criar padrões, repetir caracteres, formatar texto.
Importante: Se o número for 0, retorna string vazia. Se negativo, lança erro.
let texto = "JavaScript ";
console.log(texto.repeat(3)); // "JavaScript JavaScript JavaScript "
console.log("*".repeat(10)); // "**********"

26. match()

O que faz: Busca correspondências de uma expressão regular (regex) na string.
Quando usar: Quando você precisa buscar padrões complexos no texto.
Importante: Retorna um array com as correspondências ou null se não encontrar. Com flag /g, retorna todas as ocorrências.
let texto = "JavaScript é incrível";
console.log(texto.match(/[a-z]/g)); // ["a", "v", "a", "s", "c", "r", "i", "p", "t", "é", "n", "c", "r", "í", "v", "e", "l"] (todas as letras minúsculas)

27. matchAll()

O que faz: Retorna todas as correspondências de uma expressão regular (regex) na string.
Quando usar: Quando você precisa buscar TODAS as ocorrências de um padrão.
Importante: Requer que a regex tenha a flag /g. Retorna um iterador, não um array.
let texto = "JavaScript é incrível";
const matches = texto.matchAll(/[a-z]/g);
console.log([...matches]); // Array com todas as correspondências

28. search()

O que faz: Procura uma expressão regular (regex) na string e retorna o índice da primeira ocorrência.
Quando usar: Quando você precisa encontrar a posição de um padrão no texto.
Importante: Se não encontrar, retorna -1. Similar ao indexOf() mas aceita regex.
let texto = "JavaScript é incrível";
console.log(texto.search(/[a-z]/)); // 1 (índice do primeiro caractere minúsculo)
console.log(texto.search("é")); // 11

29. localeCompare()

O que faz: Compara duas strings considerando o idioma/local. Retorna -1, 0 ou 1.
Quando usar: Para ordenar strings em ordem alfabética correta do idioma.
Importante: -1 se a primeira for menor, 0 se iguais, 1 se a primeira for maior.
let texto1 = "a";
let texto2 = "b";
console.log(texto1.localeCompare(texto2)); // -1 (a vem antes de b)
console.log(texto2.localeCompare(texto1)); // 1 (b vem depois de a)
console.log(texto1.localeCompare("a")); // 0 (iguais)

30. valueOf()

O que faz: Retorna o valor primitivo da string (a própria string).
Quando usar: Raramente usado diretamente. JavaScript chama automaticamente quando necessário.
Importante: Em JavaScript, strings já são valores primitivos, então este método retorna a própria string.
let texto = "JavaScript";
console.log(texto.valueOf()); // "JavaScript"

31. toString()

O que faz: Retorna a string como uma string (parece redundante, mas é útil para outros tipos).
Quando usar: Quando você precisa converter outros tipos em string.
Importante: Para strings, retorna a própria string.
let texto = "JavaScript";
console.log(texto.toString()); // "JavaScript"
let numero = 123;
console.log(numero.toString()); // "123"

32. at()

O que faz: Retorna o caractere em uma posição específica. Similar ao charAt().
Quando usar: Alternativa moderna ao charAt(). Aceita índices negativos.
Importante: Método mais moderno (ES2022). Com índice negativo, conta de trás para frente.
let texto = "JavaScript";
console.log(texto.at(0)); // "J"
console.log(texto.at(-1)); // "t" (último caractere)
console.log(texto.at(100)); // undefined (não existe)
📝 Observação Importante: Todos esses métodos NÃO alteram a string original (exceto alguns casos específicos). Eles retornam uma NOVA string com o resultado. Strings em JavaScript são imutáveis.
